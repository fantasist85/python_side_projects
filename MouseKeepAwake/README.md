# MouseKeepAwake

🖱️ 마우스 움직임을 자동으로 감지하고 화면보호기/대기모드 진입을 방지하는 경량 백그라운드 프로그램

## 주요 기능

- ⏰ **10초 자동 감지**: 마우스 움직임이 10초 동안 없을 때 자동으로 1픽셀 이동
- 🪶 **초경량**: 최소한의 리소스 사용 (메모리 < 20MB)
- 🔇 **백그라운드 실행**: 시스템 트레이에서 조용히 실행
- 🎛️ **간편한 제어**: 시스템 트레이 아이콘으로 활성화/비활성화 토글
- 🔒 **안전한 코드**: 투명하고 간결한 Python 코드로 멀웨어 오탐지 최소화

## 사용 사례

- 📊 프레젠테이션 중 화면 꺼짐 방지
- 📖 긴 문서를 읽을 때 화면 유지
- 🎬 동영상 시청 중 화면보호기 방지
- 💻 장시간 모니터링 작업

## 설치 및 실행

### 방법 1: 실행 파일 사용 (권장)

1. `dist/MouseKeepAwake.exe` 실행
2. 시스템 트레이에서 마우스 아이콘 확인
3. 우클릭하여 활성화/비활성화 또는 종료

### 방법 2: Python 소스 코드 실행

```bash
# 의존성 설치
pip install -r requirements.txt

# 프로그램 실행
python main.py
```

## 빌드 방법

exe 파일을 직접 빌드하려면:

```bash
# 의존성 설치
pip install -r requirements.txt

# 빌드 스크립트 실행
python build_exe.py
```

빌드된 파일은 `dist/MouseKeepAwake.exe`에 생성됩니다.

## 시스템 요구사항

- **OS**: Windows 10/11 (또는 Linux/macOS - Python 실행 시)
- **메모리**: 20MB 이상
- **디스크**: 10MB 이상

## 기술 스택

- **Python 3.8+**
- **pynput**: 마우스 이벤트 모니터링
- **pystray**: 시스템 트레이 아이콘
- **Pillow**: 아이콘 이미지 생성
- **PyInstaller**: 실행 파일 빌드

## 작동 원리

1. 마우스 움직임, 클릭, 스크롤 이벤트를 실시간 모니터링
2. 마지막 활동 시간을 기록
3. 10초 동안 활동이 없으면 마우스를 1픽셀 이동 후 원위치
4. 시스템 트레이에서 프로그램 제어

## 보안 및 개인정보

- ✅ 로컬에서만 실행 (네트워크 통신 없음)
- ✅ 데이터 수집 없음
- ✅ 레지스트리 수정 없음
- ✅ 시스템 파일 변경 없음
- ✅ 오픈소스 (코드 검증 가능)

## 문제 해결

### 멀웨어 오탐지

일부 백신 프로그램이 마우스 제어 기능을 의심할 수 있습니다:

1. **Windows Defender**: 실행 파일을 예외 목록에 추가
2. **기타 백신**: 소스 코드를 직접 확인하거나 Python으로 실행

### 프로그램이 작동하지 않음

1. 시스템 트레이에서 프로그램이 활성화되어 있는지 확인
2. 관리자 권한으로 실행 시도
3. Python 소스 코드로 실행하여 에러 메시지 확인
